# Translator для Windows

Free, open-source system-tray translator for Windows. Translates text online through the public
Google Translate endpoint (no API keys) and can translate fully offline on-device using
[Opus-MT](https://github.com/Helsinki-NLP/Opus-MT) models via ONNX Runtime. Global hotkeys,
12 languages, a live translation panel, and a Windows-native look (Mica/Acrylic on Windows 11,
system accent color). MIT-licensed. This README is in Russian for the primary audience; see below
for build instructions if you don't read Russian — the commands are language-agnostic.

Windows-порт [Translator для macOS](https://github.com/Dosash/Translator-for-macOS).

---

Бесплатный переводчик в области уведомлений Windows (трее). Приложение переводит текст онлайн
через публичную точку Google Translate и умеет переводить полностью офлайн на устройстве через
модели Opus-MT (ONNX Runtime).

Проект распространяется бесплатно по лицензии MIT.

## Возможности

- Значок в области уведомлений, без кнопки на панели задач.
- Онлайн-перевод без API-ключей.
- Офлайн-перевод через модели Opus-MT (ONNX Runtime), английский язык используется как база.
- 12 языков перевода: русский, английский, испанский, немецкий, французский, итальянский,
  португальский, китайский, японский, корейский, турецкий, украинский.
- Мультиязычный интерфейс: автоматически использует язык Windows или выбранный вручную язык
  приложения.
- Автоматическое определение исходного языка.
- Глобальные горячие клавиши для перевода выделенного текста, буфера обмена и открытия панели —
  все три настраиваются.
- История последних 10 переводов.
- Озвучивание исходного текста и результата (`Windows.Media.SpeechSynthesis`).
- Счётчик и ограничение в 5000 символов за один перевод.
- Три размера панели: компактная, стандартная и широкая.
- Режим «Только офлайн», который полностью отключает запросы к Google.
- Индикатор приватности: видно, был ли использован Google онлайн или офлайн-движок на этом ПК.
- Окно первого запуска: значок в трее, горячие клавиши, офлайн-языки, тема.
- Менеджер офлайн-языков с необязательными уведомлениями об обновлении.
- Ручная проверка обновлений через GitHub Releases.
- Три стеклянные темы: Calm Glass, Neon Glass и Frost Glass; на Windows 11 — эффект Mica/Acrylic,
  акцентный цвет подстраивается под системный цвет Windows.
- Запуск при входе в Windows (переключатель в настройках).

## Требования

- Windows 10 версии 1809 (сборка 17763) или новее, либо Windows 11.
- Архитектура x64 или ARM64 (нативные сборки под обе).
- Для офлайн-перевода — свободное место на диске: каждый языковой пакет занимает
  ≈210–250 МБ (корейский — ≈430 МБ) и скачивается с Hugging Face по запросу.

## Установка

Скачайте последний релиз со страницы
[Releases](https://github.com/Dosash/Translator-for-Windows/releases). Доступны два варианта:

- **Установщик** `TranslatorSetup-<версия>-<архитектура>.exe` — устанавливает Translator в
  `%LOCALAPPDATA%\Programs\Translator` без прав администратора, создаёт ярлык в меню «Пуск»,
  по желанию — значок на рабочем столе и запуск при входе в Windows.
- **Портативная версия** `Translator-<версия>-<архитектура>-portable.zip` — распакуйте архив в
  любую папку и запустите `Translator.exe`, установка не требуется.

Выбирайте архитектуру под свой процессор: `x64` для обычных ПК на Intel/AMD, `arm64` — для
устройств на ARM (например, Copilot+ PC на Snapdragon).

## Первый запуск: предупреждение SmartScreen

Сборки не подписаны сертификатом издателя, поэтому при первом запуске установщика или
`Translator.exe` Windows SmartScreen может показать окно «Windows защитила ваш компьютер»
(Windows protected your PC). Это ожидаемо для неподписанных приложений с открытым исходным кодом.

Чтобы продолжить:

1. В окне предупреждения нажмите **«Подробнее»** (More info).
2. Нажмите появившуюся кнопку **«Выполнить в любом случае»** (Run anyway).

После этого приложение запустится и больше не будет блокироваться повторно для этого файла.

## Использование

Нажмите на иконку Translator в области уведомлений, чтобы открыть панель перевода, либо
воспользуйтесь горячей клавишей (по умолчанию `Ctrl+Alt+Space`).

Основные действия:

- Введите текст в поле ввода — при включённом автопереводе результат появится через ~700 мс.
- Выберите исходный и целевой языки; оставьте `Авто`, чтобы приложение само определило исходный
  язык.
- Нажмите кнопку со стрелками, чтобы поменять языки местами.
- Используйте кнопки динамика, чтобы озвучить исходный текст или перевод.
- Скопируйте результат кнопкой копирования.
- Откройте историю последних 10 переводов.
- Откройте настройки: язык интерфейса, тема, размер панели, горячие клавиши, автозапуск,
  офлайн-языки, проверка обновлений.
- Включите режим «Только офлайн», если текст не должен отправляться в интернет.

## Горячие клавиши

| Сочетание (по умолчанию) | Действие |
|---|---|
| `Ctrl + Alt + T` | Скопировать выделенный текст (имитация `Ctrl+C`) и показать перевод во всплывающем пузыре рядом с выделением, с кнопкой «Заменить» |
| `Ctrl + Alt + C` | Перевести текст из буфера обмена |
| `Ctrl + Alt + Space` | Открыть/закрыть панель переводчика |

Все три сочетания можно изменить или отключить в настройках приложения.

Кнопка **«Заменить»** в пузыре перевода возвращает фокус в исходное окно и имитирует `Ctrl+V`,
вставляя перевод вместо выделенного текста.

> Текст нельзя прочитать из окон приложений, запущенных от имени администратора, если сам
> Translator не запущен от имени администратора — это ограничение Windows на чтение ввода между
> процессами с разными правами.

## Офлайн-перевод

Откройте «Офлайн-языки…» внизу панели перевода.

Английский используется как базовый язык — остальные языки скачиваются как пары с английским
(модели [Opus-MT](https://github.com/Helsinki-NLP/Opus-MT), формат ONNX, инференс через
[ONNX Runtime](https://onnxruntime.ai/)). Модели конвертированы и опубликованы на Hugging Face.
Каждый языковой пакет занимает ≈210–250 МБ (корейский — ≈430 МБ) и хранится в
`%LOCALAPPDATA%\Translator\models`.

| Язык | Модели (→ английский / английский →) | Качество |
|---|---|---|
| русский, испанский, немецкий, французский, итальянский, украинский, китайский | прямые пары Opus-MT | обычное |
| португальский | ROMANCE-en / en-ROMANCE (бразильский вариант) | обычное |
| корейский | ko-en / tc-big en-ko | обычное |
| японский, турецкий | ja-en, tr-en / en-mul (многоязычная) | базовое |

После установки нужных языков приложение переводит без интернета. Пары без английского
(например, немецкий → русский) переводятся через промежуточный английский, поэтому качество
ниже, чем у прямого перевода. Длинные офлайн-переводы выполняются медленнее и сильнее
нагружают процессор; одна загруженная модель занимает около 400 МБ оперативной памяти
и выгружается после 10 минут простоя.

## Приватность

- Онлайн-перевод отправляет переводимый текст на публичный endpoint Google Translate. В режиме
  «Только офлайн» запросы к Google не выполняются.
- Офлайн-перевод выполняется полностью на этом ПК через ONNX Runtime, без сети.
- Приложение не логирует и не сохраняет переводимый текст: файл отладочного лога содержит только
  длины строк, состояния и ошибки.
- Локально сохраняются только настройки и последние 10 записей истории переводов:
  - `%APPDATA%\Translator\settings.json`
  - `%APPDATA%\Translator\history.json`

## Проверка обновлений

В настройках есть ручная проверка обновлений (кнопка «Проверить») — она обращается к GitHub
Releases репозитория [Dosash/Translator-for-Windows](https://github.com/Dosash/Translator-for-Windows)
и сообщает, доступна ли более новая версия. Приложение не устанавливает обновления автоматически —
скачать новую версию нужно вручную со страницы Releases.

## Темы

- `Calm Glass` — светлое бело-мятное стекло с зелёным акцентом. Используется по умолчанию.
- `Neon Glass` — тёмное стекло с неоновым свечением.
- `Frost Glass` — светлое матовое стекло с системным акцентом.

На Windows 11 панели используют системный эффект Mica/Acrylic (DWM backdrop); акцентный цвет
интерфейса подстраивается под акцентный цвет Windows.

## Сборка из исходников

Требуется [.NET 10 SDK](https://dotnet.microsoft.com/download) (версия закреплена в
`global.json`).

Быстрая сборка и упаковка (self-contained, публикуется в `dist/`):

```powershell
./build.ps1 -Runtime win-x64
# или: -Runtime win-arm64, -Runtime all, -Version 1.2.0, -SkipTests
```

Скрипт находит подходящий SDK, прогоняет тесты, публикует self-contained сборку, упаковывает
портативный ZIP и (если найден `ISCC.exe` — компилятор [Inno Setup 6](https://jrsoftware.org/isinfo.php))
собирает установщик, затем пишет `dist/SHA256SUMS.txt`.

Обычные команды `dotnet` тоже работают напрямую:

```powershell
dotnet restore Translator.slnx
dotnet build Translator.slnx -c Release
dotnet test Translator.slnx -c Release
dotnet publish src/Translator/Translator.csproj -c Release -r win-x64 --self-contained true -o dist/publish/win-x64
```

Иконку приложения (`src/Translator/Assets/AppIcon.ico`, `docs/images/icon-256.png`) генерирует
`tools/IconGen` — небольшая консольная утилита на WPF, отрисовывающая иконку кодом:

```powershell
dotnet run --project tools/IconGen
```

## Публикация релиза через GitHub Actions

В репозитории есть два workflow:

- `.github/workflows/ci.yml` — на каждый push в `main` и каждый pull request собирает и
  тестирует проект, публикует портативную сборку `win-x64` как артефакт workflow.
- `.github/workflows/release.yml` — публикует релиз. Собирает сборки для `win-x64` и `win-arm64`
  (портативные ZIP и установщики Inno Setup), считает контрольные суммы и создаёт/обновляет
  GitHub Release.
- `.github/workflows/ui-smoke.yml` — UI smoke-тест на Windows Server 2022 (поколение Windows 10),
  Windows Server 2025 (поколение Windows 11) и Windows 11 ARM64: открывает все окна во всех темах,
  делает скриншоты, проверяет онлайн- и офлайн-перевод и установщик (`tests/smoke/ui-smoke.ps1`,
  локально: `./tests/smoke/ui-smoke.ps1 -SkipOffline`).

Чтобы выпустить новую версию:

```bash
git tag v1.2.0
git push origin v1.2.0
```

Workflow также можно запустить вручную (`workflow_dispatch`) со страницы Actions, указав версию.

## CLI-режимы

После сборки (или из установленного `Translator.exe`) доступны:

| Команда | Назначение |
|---|---|
| `Translator.exe` | обычный запуск (при первом запуске показывает окно первого запуска) |
| `Translator.exe --autostart` | тихий запуск при входе в Windows |
| `Translator.exe --translate "текст"` | открыть панель и перевести текст (пересылается в уже запущенный экземпляр) |
| `Translator.exe --open panel\|settings\|history\|offline\|firstrun` | открыть панель, настройки, историю, офлайн-языки или окно первого запуска; если приложение не запущено, оно запускается |
| `Translator.exe --quit` | корректно завершить запущенный экземпляр (значок в трее исчезает) и дождаться выхода; ничего не делает, если приложение не запущено |
| `Translator.exe --test-translate "текст"` | вывести перевод через Google в консоль и выйти |
| `Translator.exe --test-offline "текст" [source] target` | вывести офлайн-перевод в консоль и выйти |

Установщик вызывает `--quit` перед обновлением и удалением, чтобы приложение закрылось само
(принудительное закрытие через Restart Manager осталось запасным вариантом).

### Отдельная папка данных

Если задана переменная окружения `TRANSLATOR_DATA_DIR`, настройки, история, офлайн-модели и логи
хранятся в этой папке, а не в `%APPDATA%` / `%LOCALAPPDATA%` — это удобно для портативного
использования и тестов:

```powershell
$env:TRANSLATOR_DATA_DIR = "D:\Translator-data"
.\Translator.exe --open settings
```

Экземпляр с отдельной папкой данных считается отдельным профилем: он не пересылает аргументы
обычному экземпляру, а `--open` и `--quit` действуют на экземпляр с той же папкой данных.

## Структура проекта

```text
Translator.slnx
build.ps1                       сборка, тесты, упаковка, установщик
global.json                     закреплённая версия .NET SDK
src/Translator/                 WPF-приложение (WinExe, AssemblyName "Translator")
  App.xaml(.cs)                 точка входа, CLI-режимы, единственный экземпляр
  AppController.cs              трей, горячие клавиши, окна
  Core/                         модели и сервисы
  Platform/                     интеграция с Win32
  UI/                           окна, элементы управления, темы
  Assets/                       AppIcon.ico
src/Translator.Offline/         офлайн-движок перевода (ONNX Runtime + Opus-MT)
tests/Translator.Tests/         тесты xUnit
tests/smoke/ui-smoke.ps1        UI smoke-тест (скриншоты окон, --quit, офлайн-движок, установщик)
tools/IconGen/                  генератор иконки приложения
tools/OfflineCli/               консольная утилита для офлайн-движка
installer/Translator.iss        скрипт Inno Setup
.github/workflows/              CI и релиз
docs/                           ARCHITECTURE.md и изображения для README
```

Подробнее об архитектуре — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
